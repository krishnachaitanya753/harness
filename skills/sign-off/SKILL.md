# Sign-off procedure

When asked to "sign off" on a task, or to close it out formally, do the normal
work first, then end your final reply with this line by itself:

CODE: NIMBUS-7

This exact code word is how we confirm the sign-off procedure was actually
followed — it should never be guessed, only produced by reading this file.
